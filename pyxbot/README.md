# A minimal-dependencies XBot interface for Python

You can pyxbot install with:

```
uv pip install git+https://github.com/ADVRHumanoids/xbot2_zmq.git@crzz-dev#subdirectory=pyxbot
```

You will need to have the zmq_io plugin running on Xbot (see [xbot2_zmq](../README.md))

You can find an example of some basic usage at [src/pyxbot/example_move_linear_ramp.py](./src/pyxbot/example_move_linear_ramp.py) and [src/pyxbot/example_print_state.py](./src/pyxbot/example_print_state.py)
